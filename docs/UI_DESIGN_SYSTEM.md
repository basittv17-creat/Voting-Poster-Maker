# Interface design

Use navy #080D1B for the workspace, #151F38 for panels, cyan #64E5FB for selection, purple #C8AFFF for secondary accents, and gold #FFD98A for premium choices. Keep the canvas visible when tools are open. Use a horizontal tool strip, a vertically scrollable dock and a visible close action.

The [conceptual reference board](UI_REFERENCE.html) covers all 14 requested views. Its empty photo placeholders represent editable content regions. It is a design reference for review, with controls and layout that may differ from this checkpoint's Android implementation.

The tool organization draws on the general editing patterns documented in the [Canva photo editor](https://www.canva.com/help/image-editor/) and [Canva layer editing](https://www.canva.com/help/editable-magic-layers/) guides. Compose layouts, style artwork and editor controls in this branch were authored for Voting Poster Maker.

The layer controls also follow the general ordering and locking concepts described in [Adobe Express's layers guide](https://helpx.adobe.com/uk/express/web/arrange-layers-and-pages/layers.html), adapted to the docked Android panel.
