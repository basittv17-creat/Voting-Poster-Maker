# Editor behavior

Choose a mode and a template. Selecting a slot from the toolbar or tapping an empty one opens Android Photo Picker. Tap a filled photo to select it. Drag the selected layer or pinch and rotate with two fingers. Each gesture forms one undo entry. Photo adjustments and replacement always use a layer ID.

Use **Remove Background** for a transparent subject preview, **Change Background** for a selected photo's backdrop, and **Background** on the lower toolbar for the canvas behind every layer. To edit titles or reorder objects, select them in **Layers**.

Use **My Designs** to reopen an autosaved project. **Canvas** includes the ten legacy ratios and the design name. **Export** renders the document at the selected long-edge size. A transparent canvas can be exported as PNG. JPEG fills transparent areas in white.
