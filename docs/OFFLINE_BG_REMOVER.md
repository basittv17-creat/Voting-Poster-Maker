# Offline background removal

MediaPipe's square SelfieSegmenter is a small person/background model available for an Android task runner. This checkpoint uses Google's Android ML Kit Selfie Segmentation artifact instead. Its model is packaged at build time and the Android API supports confidence masks in single-image mode. The pinned version, 16.0.0-beta6, is beta. ML Kit is distributed through the official Android Maven SDK under Google's API and ML Kit terms. No extracted model is redistributed separately. Review those terms and Play disclosures before public release. Google's terms describe SDK diagnostics. The native app manifest removes the Internet permission from its merged manifest.

The editor reads an oriented local bitmap, estimates foreground confidence and feathers the alpha transition. The model call is kept alive until the SDK releases its input bitmap. Cancel suppresses the result, and the preview is scoped to the originating design, layer and original asset. Applying it preserves the source; Restore Original and Undo remain available. A/B photo backdrops and the global poster background are separate document fields.

The initial implementation stores a cutout raster from a source bounded to 1536 pixels on its long edge. Fine hair, backlit subjects, busy backgrounds and non-person images may produce poor masks. Refine edges opens local Erase and Restore brushes with adjustable size and feathering. Done updates the temporary preview and Apply commits it as one undoable change. Discard brush edits leaves the temporary preview intact. Mask-only high-resolution compositing remains follow-up work.
