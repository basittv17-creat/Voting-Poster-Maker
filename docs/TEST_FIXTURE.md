# Offline test photograph

The Android test APK includes a resized JPEG of NASA's Eileen Collins portrait from scikit-image 0.25.2 (`skimage/data/astronaut.png`). The [scikit-image data documentation](https://scikit-image.org/docs/0.26.x/api/skimage.data.html#skimage.data.astronaut) identifies the portrait as public domain. The test fixture is packaged only with the instrumentation APK.
